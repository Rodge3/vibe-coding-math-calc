# Sumwise

A small browser-based arithmetic chat assistant. It calculates expressions locally and does not send data to a server.

## Run

Open `index.html` in a browser. No installation or build step is needed.

## Supported input

Use `+`, `-`, `*`, `/`, parentheses, decimals, unary signs, and `%` for percentages. For example, `18% of 240` is interpreted as `18% * 240`. The calculator uses a dedicated parser and never evaluates input as JavaScript.
